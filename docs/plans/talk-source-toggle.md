# Talk source toggle: live / mix / pre-generated pool
Status: done
Issue: none (fork-only, no upstream PR)
## Goal
One operator setting `talkSource` (`live` default, `mix`, `pool`) decides whether a scheduled station ident (and a banter slot) is written+rendered at air time or drawn from a per-persona pool of clips rendered once in advance; the hourly time check stays live and correct in every mode, and no slot fires less often than today.
